# PDF E-book Generator

Produces typeset, branded PDF e-books from an existing document, a URL, or just a
topic.

## What it does

- **Four content sources** — an existing PDF, a local text or Markdown file, a
  URL, or a researched topic.
- **Brand presets** — the whole look, meaning colours, fonts and cover, swaps with
  one switch, so the same content ships under different brands.
- **Outline templates** — archetypes such as whitepaper, how-to guide, glossary,
  listicle and case study shape the chapter structure, which is the part that
  decides whether a generated document reads as deliberate.
- **Any language**, including producing a second language alongside the first.
- **Real typesetting** rather than HTML printed to PDF, so the output holds up as
  a document people keep.
